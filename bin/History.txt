v0.0.1 (22 October 2026)
- reset fork version to 0.0.1 with its own update channel
- added automatic update check with direct in-app installer download
- the update manifest sha256 is now mandatory and the download runs over https with certificate validation always on
- the installer is downloaded to a randomly named temporary file and verified through that same handle before it runs
- fixed build against current routine sdk (removed renamed and missing api calls)
- fixed tray icon handle leak and drawing surface creation failures
- fixed volume cache flush mount point query (buffer overflow / leak)
- fixed message box titles and command line result reporting
- fixed hotkey repeat triggering (MOD_NOREPEAT)
- fixed settings: typed values in spin edit boxes are now saved
- now close button (X) hides to tray instead of quitting
- added session end handling (logoff / shutdown quits cleanly)
- tray icon rendered with the interface font, ClearType and a colour that adapts to the warning and danger backgrounds
- dark theme now follows the system switch without a restart, including an already open settings window
- the list view, tray tooltip and tray icon are only redrawn when their values changed
- purging a single memory region now asks for confirmation, like a full clean does
- the tray context menu and the clean button drop-down now actually run their commands
- the website entry and the About dialog point at the fork repository instead of the upstream project
- the About dialog only shows the version, the repository link and the license
- update failures now say which stage failed: invalid manifest or failed file verification, instead of blaming the connection
- the build workflow checks the VERSION manifest format and the installer url on every run
- the manifest sha256 is now read as the last field of the record, so a published manifest is accepted (it asked for a separator that the format does not have)
- the installer download is now capped by the announced size and by the bytes written
- the auto-clean value boxes now follow their checkbox state instead of its enabled state
- the auto-clean spin arrows are disabled together with their edit box
- a failed update request is now logged with the address that failed
- a partially failed clean now shows an error notification, and -clean without elevation returns success when the elevated copy started
- Vietnamese interface re-translated (43 strings) and the advanced page option now wraps instead of being cut off
- updated documentation
- removed the donate entry and the upstream funding link
- added 32-bit (x86) binaries and dropped arm64: windows 10/11 32-bit and 64-bit only, the installer picks the payload that matches the running windows
- all dialogs now request Segoe UI 9 instead of the logical font "Ms Shell Dlg", which windows resolves to microsoft sans serif
- the manifest declares tested support up to windows 11 build 26300 (25h2)
- the automatic update check now repeats on its period while the app sits in the tray, before it only ever ran at startup
- the tray context menu no longer leaks its menu handle when the popup has no submenu
- the installer now requires windows 10 instead of accepting windows 7 and 8
- the build workflow checks the pe headers of both binaries (machine, gui subsystem, version resource) instead of running the exe on the runner
- readme explains building from source and why git clone --recursive fails: the submodules live above the repository
- pushing a tag now also writes VERSION with the installer url and its sha256, so the update channel fills itself in
- that automatic commit refuses to point the channel at an older version than it already serves
- clicking clean, a tray region entry or the hotkey without administrator rights now cleans right after the elevation instead of waiting for a second click
- the main window is rebuilt around a fixed 400 px card layout: memory percentage, used and free, pagefile and system working set bars, and a split clean button (the list view and the menu bar are gone)
- the clean button is split: the label cleans, the caret opens the menu of the individual regions
- the window is laid out from the monitor dpi and follows a dpi change without a restart
- light and dark palettes follow the system theme, and the guest/administrator chip and footer note are localized
- the overflow button and a right click open the menu, and the language submenu is rebuilt every time it opens
- the figures in the memory card are refreshed every second, so the used and free amounts stay correct even when the percentage does not change
